Instalar o Mercatus OS

Vá marcando conforme avança. O progresso fica salvo neste navegador, então dá pra parar e voltar depois.

Antes de começar: não precisa saber programar. Mas você vai digitar comandos numa janela preta chamada terminal. Se algum passo falhar, pare e chame quem te passou este link. Não tente adivinhar. Cada tropeço aqui é problema nosso pra corrigir, não seu.
1

Instalar o Claude Code

É o programa que roda tudo. Se você nunca ouviu falar: é o Claude funcionando dentro do seu computador, com acesso às suas pastas.

Baixe em claude.com/code e siga a instalação. No fim, ele vai pedir pra você entrar com sua conta.

Como saber que deu certo: abra o terminal e digite claude --version. Tem que aparecer um número de versão.

No Windows, o terminal que funciona é o Git Bash, que vem junto com o Git do passo 2. Se você ainda não instalou o Git, faça o passo 2 primeiro e volte aqui.
2

Instalar o Git

O Git guarda todas as versões do seu trabalho. É ele que faz "desfazer" existir mesmo depois de semanas.

Baixe em git-scm.com/downloads. Pode aceitar tudo o que ele sugerir na instalação.

Como saber que deu certo: git --version mostra um número.

No Windows, ele instala junto o Git Credential Manager. É o que faz o login no GitHub abrir no navegador em vez de te pedir pra criar token na mão. Não desmarque essa opção.
3

Baixar o sistema

Escolha um dos dois caminhos.

Caminho A, com backup na nuvem (recomendado). Precisa de conta no GitHub, que é grátis. Abra github.com/pedroguedespro/Mercatus-OS e clique em "Use this template" e depois "Create a new repository". Isso cria uma cópia sua. Depois:

git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
cd SEU-REPOSITORIO

Caminho B, sem conta no GitHub. Funciona igual, só que sem backup na nuvem:

git clone https://github.com/pedroguedespro/Mercatus-OS.git meu-sistema
cd meu-sistema
git remote rename origin upstream
Aquela última linha do caminho B não é opcional. Sem ela, quando você for salvar seu trabalho o computador tentaria mandar pro repositório do sistema em vez do seu. Dá pra conectar um repositório seu depois, quando quiser.
4

Ligar a proteção contra vazamento

Uma linha só, e ela evita o acidente mais caro que existe aqui: mandar uma senha ou chave de API pro GitHub sem perceber.

git config core.hooksPath .githooks

A partir disso, todo salvamento passa por uma checagem automática, e ela cancela se achar credencial no meio.

Credencial enviada pro GitHub não se apaga: ela fica no histórico mesmo depois de você deletar o arquivo. Por isso o certo é evitar, não corrigir depois.
5

Conferir se está tudo pronto

Ainda no terminal, dentro da pasta:

bash scripts/preflight.sh

Ele checa tudo dos passos anteriores e mais algumas coisas que só dão problema depois. Leia o resultado:

TUDO CERTOSiga pro passo 6.
[!] avisoNão impede nada. Vale ler, mas pode seguir.
[X] problemaPare. Cada linha diz o que fazer. Resolva e rode de novo.
Se aparecer "COLISÃO": significa que você já tem um sistema parecido instalado no seu computador, e o comando dele venceria o nosso. Nada funcionaria como esperado, e sem mensagem de erro. Não tente resolver sozinho, manda print pra quem te passou este link.
6

Abrir o Claude Code dentro da pasta

Este é o passo que mais gente erra, e o erro é silencioso.

claude

Tem que ser de dentro da pasta que você baixou. O Claude lê o contexto da pasta onde você abre: aberto no lugar certo, ele já sabe o que é este sistema; aberto em qualquer outro lugar, ele não sabe nada e vai parecer quebrado.

Se em algum momento o Claude parecer não saber nada sobre o seu negócio, é quase sempre isso. Feche e abra de novo, dentro da pasta.
7

Rodar o setup

Digite:

/setup

Ele vai te entrevistar sobre o seu negócio, uma pergunta por vez. Responda no seu jeito de falar, sem se preocupar com formato. Quanto mais você contar, melhor fica o resultado.

No fim, você tem a estrutura montada e um manual do que fazer a partir dali.

Reserve uns 15 minutos. A entrevista é conversa, não formulário, e o resultado fica melhor quando você não está com pressa.
Nada é salvo na nuvem sozinho, de propósito. Quando quiser guardar o que fez, digite /syncar.
Travou em algum passo? Isso é informação útil: o que te travou vai travar a próxima pessoa também. Manda print do terminal pra quem te passou este link, em vez de resolver sozinho e seguir.
