Instalar o Mercatus OS

Vá marcando conforme avança. O progresso fica salvo neste navegador, então dá pra parar e voltar depois.

Não precisa saber programar. Você vai colar duas ou três frases e conversar. Se algum passo falhar, pare e chame quem te passou este link. Não tente adivinhar: cada tropeço aqui é problema nosso pra corrigir, não seu.

Parte 1: só se você ainda não tem o Claude Code

Já usa o Claude Code ou o Codex? Pule direto pra Parte 2.

1

Instalar o Git

O Git guarda todas as versões do seu trabalho. É ele que faz "desfazer" existir mesmo depois de semanas.

Baixe em git-scm.com/downloads e aceite tudo o que ele sugerir.

Deu certo? Abra o terminal e digite git --version. Tem que aparecer um número.

No Windows, ele instala junto o Git Credential Manager e o terminal Git Bash. Não desmarque nenhum dos dois.
2

Instalar o Claude Code

É o programa que roda tudo. Em uma frase: é o Claude funcionando dentro do seu computador, com acesso às suas pastas.

Baixe em claude.com/code e entre com sua conta no fim da instalação.

Deu certo? claude --version mostra um número.

Parte 2: instalar o sistema

Aqui todo mundo passa.

3

Criar a pasta e abrir o Claude Code nela

Crie uma pasta nova onde você quiser, com o nome que quiser. Pode ser na Área de Trabalho.

Abra o Claude Code dentro dela. Se estiver no terminal, entre na pasta e digite claude.

4

Pedir pra instalar

Cole isto e mande:

Instala pra mim o repositório https://github.com/pedroguedespro/Mercatus-OS.git

Ele baixa e pergunta se pode fazer a configuração inicial. Responda que sim.

São três ajustes: dois garantem que o seu trabalho não vá parar no repositório do sistema, e um liga a checagem que impede senha e chave de API de subirem por acidente. Se ele não perguntar nada, cole isto: 
Faz a configuração inicial que o README manda depois do clone
5

Conferir, se quiser garantir

Opcional, e leva dez segundos:

Roda o preflight e me diz o resultado
TUDO CERTOSiga pro passo 6.
[!] avisoNão impede nada. Pode seguir.
[X] problemaPare. Cada linha diz o que fazer.
Se aparecer "COLISÃO", você já tem um sistema parecido instalado, e o comando dele venceria o nosso sem avisar. Não resolva sozinho: manda print pra quem te passou este link.

Parte 3: usar

A partir daqui é conversa, não comando.

6

Abrir na pasta certa e dizer oi

Feche o Claude Code e abra de novo, agora dentro da pasta que ele criou. Depois mande:

oi

Ele te recebe, pergunta seu nome e o do seu negócio, e oferece montar tudo. É só ir respondendo.

Este é o passo que mais gente erra. O Claude lê o contexto da pasta onde você abre: no lugar certo ele já sabe o que é este sistema, em qualquer outro ele não sabe nada e parece quebrado. Se em algum momento ele parecer perdido, é quase sempre isso.
7

Responder a entrevista

Uma pergunta por vez, no seu jeito de falar. Quanto mais você contar, melhor fica o resultado. Reserve uns 15 minutos: é conversa, não formulário.

Se ele perguntar se você tem arquivos da empresa no computador, pode dizer o nome do arquivo ou da pasta, ou dizer que não tem. Os dois funcionam.

No fim, você tem a estrutura montada e um manual do que fazer a partir dali.

Nada é salvo na nuvem sozinho, de propósito. Quando quiser guardar o que fez, peça: salva o que a gente fez. Conectar isso ao GitHub vem depois, e não é necessário agora.
Travou em algum passo? Isso é informação útil: o que te travou vai travar a próxima pessoa também. Manda print pra quem te passou este link, em vez de resolver sozinho e seguir.
